- entropy can only be moved elsewhere, not removed
- poor prompts result in entropy moving to production
- front-loading entropy mitigates entropy down the line
- when using LLMs, cost is paid in one of 3 places:
	- writing the prompt
	- execution of prompt
	- production environment - where it shouldn't be paid!
- **frontload as much entropy as possible into the prompt, design doc, or SKILL.md, because the bill grows the longer you defer it.**
- be explicit about which decisions — which entropy collapses — we delegate to the AI versus ourselves
